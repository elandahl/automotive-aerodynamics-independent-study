# Week 5 — Reynolds number, scaling, and midterm design review

## Learning targets

- Compute $\mathrm{Re} = \rho v L / \mu$ (or $v L / \nu$) with a clear length $L$.
- Explain dynamic similarity: matching Re is hard for small models in air.
- State what the scale tests **can** claim (trends, relative ranking) vs. cannot claim (full-scale $C_D$ without care).

## Physics checkpoint

Use $\nu_{\text{air}} \approx 1.5\times 10^{-5}\,\mathrm{m^2/s}$.

1. Full-scale car: $L=4.5\,\mathrm{m}$, $v=30\,\mathrm{m/s}$. Find Re.  
2. 1:10 model: $L=0.45\,\mathrm{m}$, same air, $v=15\,\mathrm{m/s}$. Find Re. Ratio of model Re to full-scale Re?  
3. To match full-scale Re in air with the 1:10 model, what speed would you need? Is it practical?  
4. Write three sentences your final report will use as a **scaling disclaimer**.

## Design / build tasks

- Freeze model scale and primary length definition for Re.
- Midterm packet: CAD status, predicted qualitative trends, sensor plan, risk list.

## Midterm review agenda (mentor + student)

1. Physics checkpoint oral (10 min)  
2. CAD / modular interface demo (10 min)  
3. Test matrix draft (10 min)  
4. Feedback and Week 6–9 priorities (10 min)
