# CAD workspace

Use this folder for **notes and lightweight exports** (screenshots, STEP/STL descriptions, BOM).

Large proprietary CAD binaries are gitignored by default—store them in cloud drive if needed and link here.

## Suggested structure

```
cad/
  README.md          (this file)
  bom.md             (parts, fasteners, print settings)
  exports/           (optional small STL/3MF if license-clear)
  notes/             (design decision log)
```

## Naming

Match physical labels: `WING-01`, `SPLIT-02`, `DIFF-01`, `BODY-01`.
